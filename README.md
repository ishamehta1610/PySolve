# 🧮 PySolve - Student Utility Toolkit

PySolve is a beginner-friendly Python project that combines everyday calculations and student expense management into one simple, menu-driven application.

Built as a first-year Computer Science project to practise Python programming, problem-solving, functions, file handling, and error handling.

## ✨ Features

### 1. Basic Calculator
- Addition, subtraction, multiplication, and division
- Handles division by zero

### 2. Scientific Calculator
- Square roots and powers
- Factorials and logarithms
- Trigonometric calculations

### 3. Unit Converter
- Length conversion
- Weight conversion
- Temperature conversion
- Time conversion

### 4. Equation Solver
- Linear equations
- Quadratic equations
- Cubic equations

### 5. Student Expense Tracker
- Enter pocket money
- Record expenses by category
- Track food, travel, shopping, and other expenses
- View total expenses and remaining balance
- Save expense records for later use

### 6. History Management
- View previous calculations and expense records
- Store history using text files
- Clear calculation history when needed

## 🛠️ Technologies Used

- Python
- File handling
- Functions and conditional statements
- Loops and exception handling
- Mathematical operations

## 🚀 How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

```bash
python main.py
```
